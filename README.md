# Face Recognition-Based Attendance System

## 📌 Overview
This project is an automated attendance system developed during my internship at **Nimble Visions Pvt Ltd**. It uses computer vision to recognize faces via a webcam and marks attendance automatically, eliminating manual errors and proxy attendance.

## 🚀 Key Features
* **Automated Tracking:** Automatically logs date and time upon face detection.
* **Proxy Prevention:** Ensures physical presence, making the process more reliable.
* **Digital Records:** Reduces paperwork by maintaining digital logs.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** OpenCV, Pandas, Numpy, Face_Recognition
